# TaskFlow (프로젝트형 할 일 관리 프로그램)

캘린더(날짜)와 프로젝트 태그를 연계하여 할 일(To-Do)을 체계적으로 관리하는 Java 기반 애플리케이션입니다.

---

##  주요 기능

### 1. 할 일(To-Do) 관리
- **할 일 등록:** 할 일 내용, 날짜, 소속 프로젝트 태그(다중 선택 및 중복 가능) 입력
- **날짜별 조회 및 이동:** 오늘 할 일 목록 확인 및 이전/다음 날짜 이동 기능
- **상태 태그 및 필터링:** 할 일의 진행 상태(`[할 일]`, `[진행 중]`, `[완료]`) 변경 및 상태별/태그별 필터링

### 2. 프로젝트(Project) 관리
- **프로젝트 등록:** 프로젝트 이름 및 마감일 설정
- **D-Day 자동 계산:** 등록된 전체 프로젝트 목록과 마감일까지 남은 D-Day 표시
- **프로젝트별 할 일 모아보기:** 특정 프로젝트 선택 시 해당 프로젝트 태그가 지정된 모든 할 일 및 날짜 출력

## 📂 패키지 및 클래스 구조

```text
src/
├── TestMain.java        # 프로그램 시작점 (Entry Point)
├── TaskFlow.java        # 메인 메뉴 및 전체 흐름 제어 컨트롤러
├── model/
│   ├── Todo.java        # 할 일 데이터 모델
│   ├── Project.java     # 프로젝트 데이터 모델
│   └── TaskStatus.java  # 할 일 진행 상태 열거형 (Enum)
└── manager/
    ├── TodoManager.java    # 할 일 생성, 조회, 상태 변경 및 필터링 로직
    └── ProjectManager.java # 프로젝트 생성, D-Day 계산 및 소속 할 일 조회 로직


[프로그램 시작: TestMain.main()]
  │
  └──▶ TaskFlow.start() : 메인 루프 실행 (Scanner 입력 대기)
        │
        ├─ [1. 할 일(To-Do) 관리] ──▶ TodoManager.showMenu()
        │    │  * 화면 상단에 항상 [현재 기준 날짜(currentDate)]와 해당 날짜의 할 일 목록 출력
        │    │
        │    ├─ 1) 할 일 등록 : 내용(content), 날짜(date), 프로젝트 태그(projectTags, 쉼표 구분 등) 입력받아 저장
        │    ├─ 2) 상태 변경(완료 처리) : 목록 번호 선택 -> 상태(TODO / IN_PROGRESS / DONE) 변경
        │    ├─ 3) 다른 날짜 이동 : 이전 날(-1일) / 다음 날(+1일) / 특정 날짜(YYYY-MM-DD) 입력 시 currentDate 변경
        │    ├─ 4) 상태/태그 필터링 : 특정 상태나 태그만 골라서 출력
        │    └─ 0) 메인 메뉴로 돌아가기
        │
        ├─ [2. 프로젝트 관리] ──▶ ProjectManager.showMenu()
        │    │  * 화면 상단에 등록된 프로젝트 목록 + 마감일(D-Day) 함께 출력
        │    │
        │    ├─ 1) 프로젝트 등록 : 프로젝트 이름(name), 마감일(deadline) 입력받아 저장
        │    ├─ 2) 프로젝트 상세 보기(할 일 조회) : 프로젝트 번호 선택
        │    │       └──▶ [연계 핵심] TodoManager에서 해당 프로젝트 이름이 태그된 모든 Todo를 찾아 날짜와 함께 출력
        │    └─ 0) 메인 메뉴로 돌아가기
        │
        └─ [0. 프로그램 종료] ──▶ 루프 탈출 및 종료 메시지 출력
